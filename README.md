# Financial Assistant Chatbot

A stylish, interactive financial assistant powered by Google's Gemini AI. This tool helps users with budget analysis, financial advice, and real-time savings calculations.

## 🚀 Features

- **AI-Powered Chat**: Get personalized financial advice using Gemini 2.5 Flash.
- **Budget Calculator**: Real-time savings and rate calculations.
- **Interactive Charts**: Visual representation of savings vs. expenses.
- **Dark/Light Mode**: Smooth theme switching for better user experience.
- **Premium UI**: Modern Glassmorphism design with responsive layout.

## 🛠️ Setup

1. **Clone the repository** (or download the files).
2. **Setup API Key**:
   - Open the `.env` file.
   - Replace the placeholder with your actual [Gemini API Key](https://aistudio.google.com/app/apikey).
3. **Run the App**:
   - Simply open `FC.html` in any modern web browser.

> [!NOTE]  
> Since this is a client-side application, ensure you keep your API key secure if deploying publicly. For production, it's recommended to use a backend proxy.
